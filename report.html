A Tale in the Desert · Citrus trees · Model check in code

Does the citrus genetics model hold up?

A real model in code, run on the raw breeding log: 14 litters, 692 children, both parents known for each child. Every child gets an exact probability under the proposed rules. Those rules are then pitted against 31 rival rule sets, and the method itself is tested on fake data where the right answer is known.

Verdict

  • HoldsThe proposed rules explain all 692 children. They fit better than every rival with the same number of fitted values, and the gaps match what fake data made by these rules produces.
  • HoldsExactly one nudge per child. Independent nudges would put nudges in 2+ traits in about 97 children; the log has 1.
  • HoldsNudge flat on −150..+150. ±140 makes 15 children impossible; ±160 and wider fit worse; a triangular shape is 86 log-points worse.
  • HoldsColor = average, Sweet = lower gene, Size = higher gene. Every other display rule for these traits fits worse, by 69 (Sweet shown as the higher gene, the closest) up to 1,800.
  • WeakLength = gene 1 is consistent with the data, but "Length = lower gene" fits just as well once you allow for its extra freedom.
  • FixedHive 1b: the earlier page said about a third of the children were exact copies. In fact 8 of 72 are exact copies. About 34% are best explained as a copy of one parent followed by the usual single nudge.

What went against it

Held-out scoring prefers the rival. Fit on half of each litter and score the other half, and "independent nudges" wins by 253. The same test on fake logs made by the proposed rules also picks "independent nudges", 3 times out of 3. A strict model calls a held-out child impossible when it shows a hidden gene the other half never revealed (20 such children here). With logs this size, held-out scoring is biased toward lenient models, so it can't decide this question.

Length. Only gene 1 is ever visible. "Length = lower gene" gains 59 on the real log, but it gains 54–66 on fake logs where gene 1 is the truth, so the gain is just extra freedom.

Hidden genes are often only bounded. On fake logs, 68% of hidden Sweet/Size genes are recovered exactly. The rest are only known as "at least" or "at most" a value.

This is a fit, not the source code. A different mechanism that produces the same probabilities would fit equally well.

        return np.minimum(g1, g2)
    if rule == "max":
        return np.maximum(g1, g2)
    return g1 + 0 * g2  # 'g1'


def trait_rows(rule, A, B, kern, rround, need_both=False):
    """Distribution of the child's shown value (array over 0..1000) for one trait:
    'none' = no nudge on this trait, 's1'/'s2' = the nudge hit gene slot 1/2,
    'both' = both slots nudged (only needed for the 'indep' model)."""
    offs, kp = kern
    pairs = [(A[0], A[1]), (B[0], B[1]), (A[0], B[1]), (B[0], A[1])]
    rows = {k: np.zeros(V) for k in ("none", "s1", "s2")}
    if need_both:
        rows["both"] = np.zeros(V)
    for g1, g2 in pairs:
        rows["none"][display(rule, np.array(g1), np.array(g2), rround)] += 0.25
        n1 = np.clip(g1 + offs, 0, 1000)
        np.add.at(rows["s1"], display(rule, n1, np.full_like(n1, g2), rround), 0.25 * kp)
        n2 = np.clip(g2 + offs, 0, 1000)
        np.add.at(rows["s2"], display(rule, np.full_like(n2, g1), n2, rround), 0.25 * kp)
        if need_both:
            d = display(rule, n1[:, None], n2[None, :], rround)
            rows["both"] += 0.25 * np.bincount(d.ravel(), weights=np.outer(kp, kp).ravel(), minlength=V)
    return rows


def candidates(rule, v, rround="halfup"):
    """All (g1, g2) gene pairs a parent showing v can carry under a display rule,
    as a list of groups (each group is an ordered array, so a coarse-to-fine scan works)."""
    if rule == "mean":
        sums = (2 * v - 1, 2 * v) if rround == "halfup" else (2 * v, 2 * v + 1)
        groups = []
        for s in sums:
            if 0 <= s <= 2000:
                g1 = np.arange(max(0, s - 1000), min(1000, s) + 1)
                groups.append(np.stack([g1, s - g1], 1))
        return groups
    if rule == "min":
        h = np.arange(v, 1001)
    elif rule == "max":
        h = np.arange(0, v + 1)
    else:  # 'g1': gene 2 is never shown and never affects anything shown
        return [np.array([[v, 500]])]
    return [np.stack([np.full_like(h, v), h], 1), np.stack([h, np.full_like(h, v)], 1)]


class LitterFit:
    def __init__(self, df, model):
        self.m = model
        self.kern = kernel(model["shape"], model["R"])
        self.y = df[TRAITS].to_numpy()
        self.A = df[[f"A_{t}" for t in TRAITS]].iloc[0].to_numpy()
        self.B = df[[f"B_{t}" for t in TRAITS]].iloc[0].to_numpy()
        self.need_both = model["mut"] == "indep"
        isA = (self.y == self.A).all(1)
        isB = (self.y == self.B).all(1)
        self.clone_lik = 0.5 * isA + 0.5 * isB
        self.c = 0.0
        # start: mean rule -> genes split evenly; min/max -> two copies of the shown gene
        self.genes = {}
        for t, rule in enumerate(model["rules"]):
            for P, vals in (("A", self.A), ("B", self.B)):
                grp = candidates(rule, int(vals[t]), model["rround"])
                if rule == "mean":
                    g = grp[-1][len(grp[-1]) // 2]
                elif rule in ("min", "max"):
                    g = np.array([vals[t], vals[t]])
                else:
                    g = grp[0][0]
                self.genes[(P, t)] = tuple(int(x) for x in g)
        self.cols = [self._cols(t) for t in range(4)]

    def _cols(self, t, gA=None, gB=None):
        gA = gA or self.genes[("A", t)]
        gB = gB or self.genes[("B", t)]
        r = trait_rows(self.m["rules"][t], gA, gB, self.kern, self.m["rround"], self.need_both)
        yt = self.y[:, t]
        out = {"none": r["none"][yt], "s1": r["s1"][yt], "s2": r["s2"][yt]}
        if self.need_both:
            out["both"] = r["both"][yt]
        return out

    def child_lik(self, cols=None, c=None):
        cols = cols or self.cols
        c = self.c if c is None else c
        mut = self.m["mut"]
        if mut == "indep":
            p = self.m["p"]
            L = np.ones(len(self.y))
            for k in cols:
                L *= (1 - p) ** 2 * k["none"] + p * (1 - p) * (k["s1"] + k["s2"]) + p * p * k["both"]
        else:
            none = np.stack([k["none"] for k in cols])
            if mut == "one8":
                hit = np.stack([k["s1"] + k["s2"] for k in cols]) / 8
            else:  # one_g1
                hit = np.stack([k["s1"] for k in cols]) / 4
            L = np.zeros(len(self.y))
            for t in range(4):
                L += hit[t] * np.prod(np.delete(none, t, 0), 0)
        if self.m["clone"] == "nudged":
            # a copy of one parent's 8 genes that then gets the usual single nudge
            # (uses the current genes; during a scan the scanned trait lags one step,
            # the final log-likelihood is exact)
            L = (1 - c) * L + c * 0.5 * (self._self_lik("A") + self._self_lik("B"))
        elif self.m["clone"]:
            L = (1 - c) * L + c * self.clone_lik
        return L

    def _self_lik(self, P):
        none, hit = [], []
        for t in range(4):
            g = self.genes[(P, t)]
            r = trait_rows(self.m["rules"][t], g, g, self.kern, self.m["rround"])
            yt = self.y[:, t]
            none.append(r["none"][yt])
            hit.append((r["s1"][yt] + r["s2"][yt]) / 8)
        none = np.stack(none)
        return sum(hit[t] * np.prod(np.delete(none, t, 0), 0) for t in range(4))

    def loglik(self, cols=None, c=None):
        return float(np.log(self.child_lik(cols, c) + FLOOR).sum())

    def _scan_parent(self, P, t):
        rule = self.m["rules"][t]
        vals = self.A if P == "A" else self.B
        groups = candidates(rule, int(vals[t]), self.m["rround"])

        def score(g):
            g = tuple(int(x) for x in g)
            cols = list(self.cols)
            cols[t] = self._cols(t, *((g, None) if P == "A" else (None, g)))
            return self.loglik(cols), g

        # The likelihood is spiky (children land on exact values), so a plain coarse grid can
        # step over the right hidden gene. Always try every gene value that would let some
        # child's value appear exactly, plus a coarse grid, then refine around the best.
        ys = np.unique(self.y[:, t])
        other = self.genes[("B" if P == "A" else "A", t)]
        key = set(ys.tolist())
        if rule == "mean":
            for x in other:
                key |= set((2 * ys - x).tolist()) | set((2 * ys - 1 - x).tolist())
        key = np.array(sorted(key))
        best = (self.loglik(), self.genes[(P, t)])
        for grp in groups:
            step = max(1, len(grp) // 60)
            idx = set(range(0, len(grp), step)) | set(np.flatnonzero(
                np.isin(grp[:, 0], key) | np.isin(grp[:, 1], key)).tolist())
            coarse = [(score(grp[i]), i) for i in sorted(idx)]
            (s, g), i = max(coarse, key=lambda z: z[0][0])
            for j in range(max(0, i - step), min(len(grp), i + step + 1)):
                s2, g2 = score(grp[j])
                if s2 > s:
                    s, g = s2, g2
            if s > best[0] + 1e-9:
                best = (s, g)
        self.genes[(P, t)] = best[1]
        self.cols[t] = self._cols(t)

    def _scan_joint(self, t):
        """For min/max rules a value below/above both parents needs BOTH parents' hidden
        genes to move at once, which one-parent-at-a-time scans cannot find. Try every
        combination of hidden genes taken from the values seen in the children."""
        rule = self.m["rules"][t]
        if rule == "mean":
            # the parents' gene sums are only known to +-1 (rounding); try each of B's sums,
            # re-scanning A for each, and keep the best
            start = (self.loglik(), self.genes[("A", t)], self.genes[("B", t)])
            best = start
            for grp in candidates(rule, int(self.B[t]), self.m["rround"]):
                s = int(grp[0].sum())
                b1 = min(max(self.genes[("B", t)][0], s - 1000), min(1000, s))
                self.genes[("B", t)] = (b1, s - b1)
                self.cols[t] = self._cols(t)
                self._scan_parent("A", t)
                ll = self.loglik()
                if ll > best[0] + 1e-9:
                    best = (ll, self.genes[("A", t)], self.genes[("B", t)])
            self.genes[("A", t)], self.genes[("B", t)] = best[1], best[2]
            self.cols[t] = self._cols(t)
            return
        if rule not in ("min", "max"):
            return
        ys = np.unique(self.y[:, t])
        opts = {}
        for P, vals in (("A", self.A), ("B", self.B)):
            v = int(vals[t])
            hs = [h for h in ys if (h >= v if rule == "min" else h <= v)]
            opts[P] = {(v, int(h)) for h in hs} | {(int(h), v) for h in hs}
        best = (self.loglik(), self.genes[("A", t)], self.genes[("B", t)])
        cols = list(self.cols)
        for gA in opts["A"]:
            for gB in opts["B"]:
                cols[t] = self._cols(t, gA, gB)
                s = self.loglik(cols)
                if s > best[0] + 1e-9:
                    best = (s, gA, gB)
        self.genes[("A", t)], self.genes[("B", t)] = best[1], best[2]
        self.cols[t] = self._cols(t)

    def fit(self, rounds=8):
        prev = -np.inf
        for _ in range(rounds):
            for t in range(4):
                if self.m["rules"][t] == "g1":
                    continue
                self._scan_joint(t)
                self._scan_parent("A", t)
                self._scan_parent("B", t)
            if self.m["clone"]:
                grid = np.r_[0, np.linspace(0.005, 0.6, 120)]
                self.c = float(grid[np.argmax([self.loglik(c=c) for c in grid])])
            ll = self.loglik()
            if ll - prev < 1e-6:
                break
            prev = ll
        return ll

    def score_other(self, df):
        """Log-likelihood of other children (held-out) under this litter's fitted genes."""
        other = LitterFit(df, self.m)
        other.genes, other.c = dict(self.genes), self.c
        other.cols = [other._cols(t) for t in range(4)]
        return other.loglik(), other.child_lik()


def fit_all(df, model):
    fits = {}
    for name, d in df.groupby("litter", sort=False):
        f = LitterFit(d, model)
        f.fit()
        fits[name] = f
    return fits


def simulate(fit, n, rng):
    """Draw n children from a fitted litter (its genes, nudge model and clone share)."""
    m = fit.m
    offs, kp = fit.kern
    out = np.zeros((n, 4), dtype=int)
    for i in range(n):
        if m["clone"] and rng.random() < fit.c:
            out[i] = fit.A if rng.random() < 0.5 else fit.B
            continue
        genes = np.zeros((4, 2), dtype=int)
        for t in range(4):
            for s in range(2):
                src = fit.genes[("A" if rng.random() < 0.5 else "B", t)]
                genes[t, s] = src[s]
        if m["mut"] == "one8":
            hits = [divmod(rng.integers(8), 2)]
        elif m["mut"] == "one_g1":
            hits = [(rng.integers(4), 0)]
        else:
            hits = [(t, s) for t in range(4) for s in range(2) if rng.random() < m["p"]]
        for t, s in hits:
            genes[t, s] = np.clip(genes[t, s] + rng.choice(offs, p=kp), 0, 1000)
        out[i] = [display(m["rules"][t], genes[t, 0], genes[t, 1], m["rround"]) for t in range(4)]
    return out

2. Hidden-gene recovery: on the fake CLAIM datasets, how often does the fit get the planted

3. Posterior-predictive check: simulate the real litters many times from the fitted CLAIM
   model and compare simple counts (children with 0 / 1 / 2+ visibly changed traits, and

Usage: python sim_checks.py [p_indep]   (default 0.11). Writes results/sim_checks.txt.

def fake_dataset(gen_name, seed):
    df = pd.read_csv(HERE / "data" / "children.csv")
    rng = np.random.default_rng(seed)
    parts, truth = [], {}
    for lit, d in df.groupby("litter", sort=False):

        f.fit()
        y = simulate(f, len(d), rng)
        dd = d.copy()
        dd[TRAITS] = y
        parts.append(dd)
        truth[lit] = dict(f.genes)
    return pd.concat(parts), truth


def recovery_job(args):
    gen_name, seed = args
    fake, truth = fake_dataset(gen_name, seed)
    ll, cv, hits, tot = {}, {}, 0, 0
    for name, m in MODELS.items():
        s, c = 0.0, 0.0
        for lit, d in fake.groupby("litter", sort=False):
            f = LitterFit(d, m)
            s += f.fit()
            for tr, te in ((d.iloc[0::2], d.iloc[1::2]), (d.iloc[1::2], d.iloc[0::2])):
                g = LitterFit(tr, m)
                g.fit()
                c += g.score_other(te)[0]
            if name == gen_name == "CLAIM":
                for t in (1, 2):
                    for P in "AB":
                        tot += 1
                        hits += sorted(f.genes[(P, t)]) == sorted(truth[lit][(P, t)])
        ll[name], cv[name] = round(s, 1), round(c, 1)
    return gen_name, seed, ll, cv, (hits, tot)


def support(f, t):
    r = trait_rows(f.m["rules"][t], f.genes[("A", t)], f.genes[("B", t)], kernel("uniform", 150), f.m["rround"])
    return set(np.flatnonzero(r["none"] > 0).tolist())


def changed(f, y):
    """Per child and trait: True if the shown value cannot come from the 4 gene pairs
    without a nudge (a visibly nudged trait), given the fitted genes."""
    sup = [support(f, t) for t in range(4)]
    return np.array([[y[i, t] not in sup[t] for t in range(4)] for i in range(len(y))])


def ppc(n_sims=300, seed=1):
    df = pd.read_csv(HERE / "data" / "children.csv")
    rng = np.random.default_rng(seed)
    obs_k, obs_tr = np.zeros(3), np.zeros(4)
    sim_k, sim_tr = np.zeros((n_sims, 3)), np.zeros((n_sims, 4))
    for lit, d in df.groupby("litter", sort=False):
        f = LitterFit(d, CLAIM)
        f.fit()
        ch = changed(f, d[TRAITS].to_numpy())
        k = np.minimum(ch.sum(1), 2)
        obs_k += np.bincount(k, minlength=3)
        obs_tr += ch.sum(0)
        for s in range(n_sims):
            cs = changed(f, simulate(f, len(d), rng))
            sim_k[s] += np.bincount(np.minimum(cs.sum(1), 2), minlength=3)
            sim_tr[s] += cs.sum(0)
    return obs_k, obs_tr, sim_k, sim_tr


def indep_two_trait_expectation(n_sims=200, seed=2):
    """If nudges were independent per gene (the best rival), how many children would show
    nudges in 2+ traits? Uses the rival's own fitted genes."""
    df = pd.read_csv(HERE / "data" / "children.csv")
    rng = np.random.default_rng(seed)
    obs, sims = 0, np.zeros(n_sims)
    for lit, d in df.groupby("litter", sort=False):
        f = LitterFit(d, MODELS["INDEP"])
        f.fit()
        obs += int((changed(f, d[TRAITS].to_numpy()).sum(1) >= 2).sum())
        for s in range(n_sims):
            sims[s] += (changed(f, simulate(f, len(d), rng)).sum(1) >= 2).sum()
    return obs, sims

TRAITS = ["color", "sweet", "size", "length"]


def read_litters(path=SRC):
    ws = openpyxl.load_workbook(path, data_only=True, read_only=True)["Data"]
    rows = [list(r) for r in ws.iter_rows(values_only=True)]
    out = []
    for i, r in enumerate(rows):
        if len(r) > 1 and r[1] == "Color" and isinstance(r[2], (int, float)):
            block = rows[i:i + 4]
            assert [b[1] for b in block] == ["Color", "Sweet", "Size", "Length"], i
            name = str(r[0]).replace(" ", "")
            A = [int(b[2]) for b in block]
            B = [int(b[3]) for b in block]
            n = 0
            for col in range(5, max(len(b) for b in block)):
                vals = [b[col] if col < len(b) else None for b in block]
                if all(v is None for v in vals):
                    continue
                assert all(isinstance(v, (int, float)) for v in vals), (name, col, vals)
                n += 1
                out.append({"litter": name, "child": n,
                            **{f"A_{t}": a for t, a in zip(TRAITS, A)},
                            **{f"B_{t}": b for t, b in zip(TRAITS, B)},
                            **{t: int(v) for t, v in zip(TRAITS, vals)}})
    return pd.DataFrame(out)


if __name__ == "__main__":
